# TradingCrier — спеки источников данных

Готовые конфигурации «своего источника» (схема `tradingcrier.source/2`) для Android-приложения **TradingCrier**.

Спека — это JSON-описание REST API площадки: куда слать запрос, как приложить ключ и где в ответе лежат свечи, цена и список инструментов. Приложение читает спеку и ходит в API **напрямую с телефона** — без серверов-посредников и без передачи ключа третьим лицам.

## Что в каталоге

| Файл | Площадка | Ключ | Данные |
|---|---|---|---|
| `exchange_iss_v2.json` | Московская биржа — ISS | не нужен | с задержкой ~15 минут |
| `broker_rest_v2.json` | Т-Инвестиции API (REST) | токен «только чтение» | без задержки |

Спеки описывают только методы рыночных данных. Операций со счётом (заявки, портфель, вывод средств) в них нет и быть не может — приложение такие адреса не сохранит.

## Установка через каталог (рекомендуется)

1. В приложении: **Настройки → «Источник данных» → «Каталог спек»**.
2. Вставьте адрес индекса:

   ```
   https://raw.githubusercontent.com/tradingcrier/tradingcrier/main/catalog.json
   ```

   > Адрес должен начинаться с `https://raw.githubusercontent.com/`. Ссылка вида `github.com/.../raw/...` не подойдёт — она отдаёт редирект, а приложение редиректы не проходит.

3. Нажмите **«Проверить обновления»** — появится список спек.
4. **«Установить»** у нужной спеки. Приложение само скачает файл и сверит контрольную сумму с индексом — битый или подменённый файл не установится.

## Установка вручную (без каталога)

1. Откройте файл спеки на GitHub → **Raw** → сохраните на телефон (или скопируйте весь текст).
2. **«Источник данных» → «Загрузить файл спеки» → «Выбрать файл»** — или **«Из буфера»**, если скопировали текст.

## После установки

1. На экране спеки заполните **поля доступа** (для Т-Инвестиций — токен с правом «только чтение» и метка приложения; для ISS полей нет).
2. Нажмите **«Проверить подключение»** — все шаги должны быть зелёными. Без этого новый источник не сохранить.
3. **«Сохранить»** → выберите источник в списке → закрепите нужные инструменты через поиск.

Ключ хранится только на телефоне (Android Keystore), не попадает в экспорт конфига и в резервные копии.

## Обновления

Когда в каталоге выходит новая версия спеки, приложение на экране каталога покажет **«Доступно обновление»** → «Обновить». Ключи и алерты при обновлении сохраняются (источник сопоставляется по полю `name`).

## Требования и ограничения

- TradingCrier версии **1.3.0** и новее (поле `minEngine` в спеке).
- Свои источники работают в расширенном режиме (пробный период).
- **ISS**: данные с задержкой ~15 минут; таймфреймов 5м, 15м и 4ч у ISS нет — на этих ТФ график не построится.
- **Т-Инвестиции**: токен живёт 3 месяца с последнего использования — выпускайте «только для чтения». Песочница — переключателем «Боевой/Песочница» на экране спеки (для неё нужен отдельный sandbox-токен и своя метка приложения).

## Как устроена спека

Верхнеуровнево: `baseUrl` — адрес API, `auth`/`secrets` — как прикладывается ключ, `timeframes` — как кодируются таймфреймы, `candles`/`ticker`/`instruments` — методы и разбор ответа (JSON-пути, формат времени и цен), `limits` — вежливость к API (паузы, повторы).

Подробная методичка с разбором полей, плейсхолдерами `{{symbol}}`, `{{interval}}`, `{{secret:...}}` и рецептами под другие API — в файле `custom_source_guide.md`.

## Хочу спеку для другого API

- Откройте **issue** с названием площадки и ссылкой на документацию API.
- Либо соберите спеку сами по методичке и пришлите **pull request**. Требования к PR:
  - спека проходит «Проверить подключение» в приложении на живом ключе;
  - только GET/POST к методам рыночных данных, без операций со счётом;
  - значение ключа в JSON не вставляется — только плейсхолдер `{{secret:...}}`;
  - `name` существующей спеки между версиями не меняется, `version` повышается.
